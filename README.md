# EECE7205
Personal repository of Eduardo Scopelli for the EECE7205 NE class of Fundamentals of Computer Engineering for the Fall 2026 Term.

This repository will include files for all exercises and assignments made for this course, utilizing C++.

CURRENT FILES
- Assignments/Assignment01: - 24-09-26
  - Assignment01_Scopelli.cpp: Main C++ file for Assignment 01, including functions for each of the 10 problems in the assignment, as well as a testCases() function including various test cases per problem and a final message for each after successfully executing each test.
  - Assignment01_Scopelli.zip / .pdf: Downloaded report files from Overleaf with the assignment 01 report.
- Class_work/Classwork01: - 29-09-26
  - SortPractice01.cpp: Main C++ file for InClassWork 01, including functions for each of the 6 sorting algorithms in the assignment, as well as additional auxiliary functions based on the assignment's instructions (printing arrays, testing the algorithms, helper functions).
  - ClassWork01_Scopelli.zip / .pdf: Downloaded report files from Overleaf with the classwork 01 report.
- Class_work/Classwork03: - 18-10-26
  - BST_Classwork.cpp: Main C++ file for InClassWork 03, including functions for the different cases for deleting nodes of binary search trees with the variations requested in the class work assignment, as well as a general function for deleting any node of a binary search tree. Additionally, this file contains some helper functions for defining nodes, creating binary trees, printing a tree's inorder traversal, and selecting which case to execute.
  - ClassWork03_Scopelli.zip / .pdf: Downloaded report files from Overleaf with the classwork 03 report.
